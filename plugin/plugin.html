安全提示

  • 插件场景建议设置 MONITOR_HOST=127.0.0.1，并启用 MONITOR_TOKEN。
  • Token 只通过 postMessage 传递给 iframe，不会出现在 iframe URL 或 Referer 中。
  • /widget 的父页面白名单由 MONITOR_FRAME_ANCESTORS 控制，默认仅本机；接入外部域名时显式追加。
  • 页面统一带 Referrer-Policy: no-referrer、X-Content-Type-Options: nosniff 与 frame-ancestors。
