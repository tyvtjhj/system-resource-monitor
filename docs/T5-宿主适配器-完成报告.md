## 3. 关键实现说明

### 3.1 用户脚本（T5.2）

- 取数走 `GM_xmlhttpRequest`，不受页面 CSP / HTTPS 混合内容限制，因此适合在 HTTPS 聊天页使用；
- 渲染：拉取服务端 `/widget-core.js` 后执行，在 Shadow DOM 中渲染；加载失败时使用内置极简渲染兜底；
- 不用 iframe；token 存 `GM_setValue`，菜单可设置服务地址 / token / 目标选择器，重置位置；
- 轮询 2 秒，失败退避 2s→5s→10s，状态点变红显示「离线」；页面隐藏时暂停；
- 拖动标题栏移动，位置存 GM 存储。

### 3.2 DSH 适配器（T5.1）

- `adapter.config.json` 提供默认配置，`inject.js` 读取同目录配置（也可用 `window.DSH_HARDWARE_MONITOR_CONFIG` 覆盖）；
- 目标选择器无效时回退到视口左上角并在控制台提示；
- 无法注入时文档明确退回用户脚本或独立窗口，不承诺聊天 DOM 注入。

### 3.3 VS Code 系扩展（T5.3）

- 扩展宿主轮询（Node `fetch`），Webview 不直接联网 → 不存在 CORS/混合内容问题；
- Webview 使用 CSP nonce + `default-src 'none'`，`widget-core.js`/`widget.css` 由扩展宿主拉取后内联；
- 命令：打开完整面板（外部浏览器）、显示/隐藏侧边栏、刷新；
- 明确不注入内置聊天 DOM；Trae/Cursor 按 VS Code 兼容扩展实现，需逐平台验证 API 兼容性。

### 3.4 Codex 状态行（T5.4）

- 仅用标准库 `urllib`；`--base-url` / `--token` / `--format`；
- 默认格式 `CPU {cpu}% | MEM {mem}% | GPU {gpu}% | {temp}°C`，缺失字段输出 `--`；
- 服务不可用 / 401 / 超时：stdout 输出单行 `--`，stderr 记录原因，退出码 1。

### 3.5 原生 DSH 插件（DSH 兼容补强）

DSH 是 Electron/Web 宿主，支持 client plugin + host plugin；仅靠 `inject.js` 无法进入 DSH 自身 UI。
因此 `plugins/dsh-hardware-monitor/` 同时提供**原生 DSH 插件**（格式参考本机 `dsh-netwatch`）：

| 文件 | 作用 |
|---|---|
| `package.json` | DSH 插件清单（`dsh.bundle.patch` / `dsh.client.platform=web` / `inject`） |
| `client.js` | 浏览器半：React 组件挂到 `conversation.session.header.corner`（回退 `conversation.composer.dock`），2s 轮询同源代理、失败退避、点击展开明细与完整面板链接 |
| `lib/index.js` | 宿主半：注册 `/hardware-monitor-api/{summary,health}` 同源代理 + `hardware_monitor_status` 工具 |
| `cordis.patch.yml` | bundle patch：把插件行插入 profile |
| `install.ps1` / `uninstall.ps1` | junction + profile bundle 注册 + skill 安装 + 热加载（卸载可逆，自动备份） |
| `SKILL.md` | 工具使用说明，安装到 `~/.dsh/skills/hardware-monitor` |

环境变量（启动 DSH 前设置）：`HARDWARE_MONITOR_URL`（默认 `http://127.0.0.1:5678`）、
`HARDWARE_MONITOR_TOKEN`（对应服务端 `MONITOR_TOKEN`）。
`adapter.config.json` + `inject.js` 保留为「无插件管理器」的 Web 注入回退。

## 6. 已知限制

1. 用户脚本执行 `widget-core.js` 依赖服务地址可达；该脚本本身不做 token 加密（HTTPS 页面建议配合工具或仅本机）。为支持自定义地址，脚本声明了较宽的 `@connect *`，请只把服务地址指向可信主机。
2. Trae/Cursor 的扩展 API 兼容性需逐平台验证；不兼容时按文档降级为用户脚本 + 独立页面。
3. VS Code 系内置聊天区无法注入 DOM，这是平台限制，不是实现缺失。
4. 状态行脚本仅输出单行文本；若 Codex 版本不支持自定义状态行，可放在独立终端面板。
5. DSH 原生插件的客户端半需刷新页面（Ctrl+R）生效；slot 名称随 DSH 版本可能变化，届时更新 `client.js`。
6. 插件 token 通过启动 DSH 的环境变量注入；挂件里的「打开完整面板」默认不带 token，可在 DSH 控制台写入 `localStorage.hardware-monitor-token` 让链接自动携带。
