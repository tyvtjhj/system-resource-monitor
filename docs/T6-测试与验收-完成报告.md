## 7. 重启自动恢复（补充）

DSH 宿主半新增 `ensureService()`：插件 apply 时检测 `/api/start`，服务未运行则用仓库 `.venv` Python 以 `-m hardware_monitor --no-elevate` 后台拉起；30 秒看门狗兜底；可用 `HARDWARE_MONITOR_AUTOSTART=0` 关闭，日志写 `plugins/dsh-hardware-monitor/service.log`。
这解决了「DSH 重启后 5678 未启动 → 挂件零值/模块离线、面板拒绝连接」的问题。
