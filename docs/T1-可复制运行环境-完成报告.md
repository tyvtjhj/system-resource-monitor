### 2.4 关于 `pip-compile --universal` 的偏差说明

任务书 T1.2 要求 `pip-compile --universal`，但实测 **pip-tools 7.6.2（PyPI 最新）没有 `--universal` 选项**（`pip-compile --help` 不含该开关，报 `No such option`）。为满足「跨平台锁文件」目标，改用 uv 0.9.2 的 `uv pip compile --universal --python-version 3.10` 生成；锁脚本已强校验 uv 与 marker，**不再提供会丢失 marker 的 pip-compile 回退**。README「依赖锁文件维护」已注明。

## 4. 环境问题与规避（记录）

1. **中文注释导致 pip 解码失败**：pip 按系统 locale 解码 requirements 文件，UTF-8 中文注释在 GBK 中文 Windows 上直接 `UnicodeDecodeError`。→ 所有 `.in` / `.txt` 依赖文件保持 ASCII。
2. **本机 pip 23.0.1 异常**：`pip install --upgrade pip`、`pip list`、无特殊参数的 `pip install -r` 会长时间卡住（CPU 空转，疑似沙箱下 pip 缓存/临时目录写入受限）。规避：`PIP_NO_CACHE_DIR=1`、`PIP_DISABLE_PIP_VERSION_CHECK=1`、`PIP_PROGRESS_BAR=off`；bootstrap 已加 `--disable-pip-version-check`，README 记录该规避方式。**正常桌面环境通常不需要。**
3. **DSH 沙箱内 `%TEMP%` 不可写**：`win32com` 的 `gen_py` 缓存报 `PermissionError`，导致 WMI 导入失败；测试时用 `TEMP` 指向项目内 `.tmp` 规避。普通 PowerShell / 双击 `run.bat` 不受影响。
4. **pip-tools 无 `--universal`**：见 §2.3；锁脚本要求 uv，缺失时拒绝执行。
5. **uv 生成锁时会把 `-o` 参数写进文件头**：脚本生成到临时文件后会把该行改写回最终文件名，保证提交内容与直接生成一致（已验证 `git diff` 为空）。
