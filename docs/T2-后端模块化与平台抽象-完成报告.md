## 2. 平台抽象接口

两个平台模块都提供同名函数，由 `platform/__init__.py` 统一导出：

| 接口 | Windows | Linux |
|---|---|---|
| `is_elevated()` | `IsUserAnAdmin()` | `os.geteuid() == 0`（无 geteuid 时 False） |
| `request_elevation(argv)` | UAC `ShellExecuteW("runas")`，带 `--elevated` 防递归 | 始终 False（不调用 sudo） |
| `subprocess_flags()` | `{"creationflags": CREATE_NO_WINDOW}` | `{}` |
| `physical_disks()` | WMI `Win32_DiskDrive` | 遍历 `/sys/block`，排除 loop/ram/dm/sr/zram |
| `network_details()` | WMI `Win32_NetworkAdapterConfiguration` + psutil 按 MAC/IP 合并，失败回退纯 psutil | psutil + `/proc/net/route` + `/etc/resolv.conf` |
| `temperature_sources()` | `[lhm, ohm, acpi, wmi]` 四个可调用来源 | `[hwmon, thermal]` 两个可调用来源 |
| `integrated_gpu()` | `GpuPerfReader`（GPU Engine/Memory 性能计数器，进程内单例） | amdgpu sysfs（busy%、VRAM、hwmon 温度），Intel/无数据返回 None |
| `capabilities()` | `os=windows`，4 个温度来源，lhm/powershell=True | `os=linux`，2 个温度来源，lhm/powershell=False |

能力表语义：**表示平台支持什么，不代表设备一定存在**（设备缺失仍返回 `null`，前端显示 `--`）。

## 3. API 变更（向后兼容）

| 接口 | 变化 |
|---|---|
| `GET /api/all` | 新增顶层 `platform` 字段：`{"os": "windows"/"linux", "capabilities": {...}}`；其余字段/状态码不变 |
| `GET /api/start` | 新增 `platform`（字符串）与 `capabilities`（对象）；原有 `status/ready/host/port/elevated` 不变 |
| 其它路由 | 无变化（`/api/<key>` 值缺失仍返回 503） |

## 5. 已知边界

1. macOS 目前走 Linux 实现（best-effort：无 sysfs 时返回空/None，不崩溃），不在本期正式范围。
2. Linux `physical_disks()` 额外附带 `rotational`；`integrated_gpu()` 可选附带 `vram_total_gb` / `temperature_c`，前端会忽略未知字段。
3. 前端（T3）尚未适配：`API_BASE` 仍是 `http://host:port`，`hwmon/thermal` 温度标签未映射（会原样显示来源字符串），平台中性文案未替换——这些属于 T3。
4. T4/T5/T6（插件、适配器、文档与发布）未开始。
