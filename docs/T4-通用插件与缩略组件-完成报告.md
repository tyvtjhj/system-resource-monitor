## 2. 后端路由与安全响应头（T4.1）

| 路由 | 返回 | 关键响应头 |
|---|---|---|
| `GET /plugin` | `plugin/plugin.html` | `Referrer-Policy: no-referrer`、`X-Content-Type-Options: nosniff`、`Cache-Control: no-cache`、`CSP: frame-ancestors 'self'` |
| `GET /widget` | `plugin/widget.html` | 同上，`CSP: frame-ancestors <MONITOR_FRAME_ANCESTORS>`（默认 `'self' http://127.0.0.1:* http://localhost:*`） |
| `GET /embed.js` | `plugin/embed.js` | `Content-Type: application/javascript; charset=utf-8`、`Cache-Control: no-cache` |
| `GET /api/plugin/manifest` | JSON | 名称/版本/`api_version`/`base_url`/`widget_url`/`dashboard_url`/`auth`/`platform{os,capabilities}` |
| `/widget.css` `/widget-core.js` `/widget.js` `/plugin.css` | 静态资源 | 正确 Content-Type、`no-cache`、`nosniff` |

- 统一**不使用** `X-Frame-Options`（避免与 `frame-ancestors` 冲突）。
- `/api/plugin/manifest` 受 token 保护（设置 `MONITOR_TOKEN` 后 401）；插件静态资源不受 token 保护，便于 iframe 加载。
- `MONITOR_FRAME_ANCESTORS` 已加入 `config.py`（T1 的 `.env.example` 早已列出）。

## 3. 缩略组件（T4.2）

- 尺寸：展开 320×180，折叠 132×36（含 1px 边框时实测 322×182 / 134×38）。
- 指标：CPU、MEM、GPU、TEMP、DOWN、UP；缺失显示 `--`；按占用阈值着色（>80 红 / >60 橙）。
- 主题：`auto | light | dark`，`auto` 跟随 `prefers-color-scheme`，无 Google Fonts。
- 轮询 `/api/all` 每 2 秒；页面隐藏时暂停；失败退避 `2s → 5s → 10s`，状态点变红并显示「离线」。
- 交互：折叠/展开、打开完整面板、关闭；位置与折叠状态存 `localStorage`。
- `widget-core.js` 暴露约定 API：`mount(container, options)`、`render(data)`、`setTheme(theme)`、`destroy()`，并额外提供 `setCollapsed()` 便于宿主复用。

## 4. 嵌入脚本 `embed.js`（T4.3）

- 解析 `data-target`、`data-position`、`data-theme`、`data-base-url`、`data-token`、`data-collapsed`、`data-auto`。
- Shadow DOM 隔离宿主样式；优先 `absolute` 挂到 `data-target`（自动补 `position: relative`），缺省 `fixed` 视口左上角。
- iframe 加载 `/widget?embed=1`，postMessage 握手：
  1. iframe → 宿主 `monitor:ready`；
  2. 宿主 → iframe `monitor:init`（baseUrl / token / theme / collapsed）；
  3. 宿主 → iframe `monitor:set-theme` / `monitor:refresh` / `monitor:collapse`；
  4. iframe → 宿主 `monitor:state`（online / collapsed / theme / platform）。
- 校验 `event.source === iframe.contentWindow` 且 `event.origin === baseUrl origin`；**token 只走握手，不进入 iframe URL**。
- 拖动标题栏移动组件（位置存 `localStorage`）；能力开放 `window.HardwareMonitor.mount/unmount/toggle/setTheme/refresh/getState`。

## 7. 已知限制

1. 拖动/折叠状态只存 `localStorage`，不跨设备同步（本期无后端持久化）。
2. 失败退避的**具体时序**（2s→5s→10s）已实现，但无头验证只断言了「离线状态」与重试（未测量精确时间）。
3. `/widget` 默认只允许本机父页面；接入外部 https 宿主需显式配置 `MONITOR_FRAME_ANCESTORS`。
4. 集成中心的「复制」使用 `document.execCommand('copy')` 兼容路径，未使用 Clipboard API（避免权限弹窗差异）。
5. T5 的用户脚本将复用 `widget-core.js`；VS Code 系扩展不承诺注入内置聊天 DOM。
